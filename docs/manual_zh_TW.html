MineOrganizer 使用者手冊

MineOrganizer 是一套集中管理 Minecraft 遊戲環境、模組 (Mod)、世界存檔、材質包、光影、設定檔與備份的桌面管理工具。它將不同啟動器的檔案彙整至單一工作區中，協助您安全管理並切換完整的遊戲內容設定。

核心功能

當您擁有複數個 Minecraft 安裝環境或模組收藏，並希望進行以下作業時，請使用 MineOrganizer：

  • 自動偵測來自 Prism Launcher、CurseForge、Minecraft 官方啟動器、TLauncher 與自訂遊戲目錄的環境；
  • 維護集中化的高效能模組庫，支援拖放匯入 (Drag & Drop) 與模組圖示快取；
  • 透過內建的 Modrinth 模組庫 直接搜尋、下載與一鍵檢查更新模組；
  • 自動偵測設定檔中缺少的必要前置模組相依性；
  • 利用內建的當機報告與記錄檔分析器快速排查遊戲崩潰與閃退問題；
  • 以 .morgpack / .zip 格式完整匯出與匯入整合包（包含模組、設定檔、材質包、光影與世界存檔）；
  • 透過 saves 分頁整理並安裝世界存檔，無需手動翻找遊戲目錄；
  • 使用安全的虛擬連結套用包含模組、材質與光影的設定檔；
  • 建立帶有時間戳記的設定備份，並支援一鍵安全還原。

安全提示： 預覽與環境檢查皆為唯讀作業。在套用設定檔、安裝資源、還原備份或修改作用中環境的檔案前，請務必先關閉 Minecraft 遊戲客戶端。

初次啟動

  1. 開啟設定 → 語言並選擇偏好的介面語言。繁體中文與英文以及其他9種語言皆獲得完整支援。
  2. 在檢視功能表中選擇淺色或深色佈景主題，設定將自動儲存。
  3. 進入遊戲環境分頁並點擊重新整理，MineOrganizer 將掃描已知的啟動器路徑。
  4. 若未自動偵測到環境，可使用新增遊戲資料夾…、選擇 Prism 資料夾…或為官方啟動器建立執行個體。

模組庫與拖放匯入 (Drag & Drop)

  1. 快速匯入 (Drag & Drop)：直接將一個或多個模組 JAR 檔案從檔案總管拖曳至模組庫表格中。系統將立即複製、解析並顯示快取的模組圖示。
  2. 標準匯入：點擊工具列上的匯入 JAR…按鈕並選取檔案。
  3. 使用即時搜尋與多重篩選器（Minecraft 版本、載入器、相容性）在大型模組庫中迅速瀏覽。
  4. 以滑鼠右鍵點擊任一項目即可檢視詳細資料、編輯標籤、覆寫 Minecraft 版本或移除模組。

Modrinth 模組庫與自動更新

從 Modrinth 瀏覽並安裝

  1. 在模組庫中點擊 Modrinth 模組庫。
  2. 輸入關鍵字搜尋，並依 Minecraft 版本與模組載入器（Fabric、Forge、NeoForge、Quilt）進行篩選。
  3. 檢視模組說明、作者、下載次數與相容性。點擊下載按鈕即可將相容版本的 JAR 檔案直接加入模組庫。

檢查更新

  1. 在模組庫或設定檔捷徑功能表中點擊檢查更新。
  2. MineOrganizer 會將檔案的雜湊值（SHA-1 / SHA-512）與 Modrinth API 比對。
  3. 在更新視窗中勾選欲更新的模組，點擊更新選取項目即可自動下載最新版本。

設定檔與相依性解析

設定檔是針對特定 Minecraft 遊戲環境所配置的一組專屬模組與資源集合。

  1. 進入設定檔分頁，選取目標環境並點擊建立設定檔…。
  2. 選取該設定檔並點擊修改模組…。
  3. 勾選應包含於設定檔中的模組。
  4. 自動相依性解析：若選取的模組缺少必要的前置模組（如 Fabric API），程式會在相容性欄位發出提示，並支援一鍵前往 Modrinth 模組庫下載。

整合包匯出與匯入

匯出整合包

  1. 選取設定檔，點擊檔案功能表或工具列中的匯出整合包…。
  2. 在選項對話方塊中勾選欲封裝的項目：
    • 模組 (JAR 檔案)：設定檔內選取的模組。
    • 設定檔 (config 資料夾)：當前環境的模組設定檔。
    • 材質包：resourcepacks 目錄下的材質包。
    • 光影包：shaderpacks 目錄下的光影包。
    • 世界存檔：saves 目錄下的存檔。
  3. 儲存為 .morgpack 或 .zip 格式。

匯入整合包

  1. 點擊檔案功能表中的匯入整合包…。
  2. 選取 .morgpack、.zip 或 .mrpack 檔案。
  3. 指定新設定檔名稱與目標環境。所有模組、設定、資源與世界將自動解壓縮並準備就緒！

套用設定檔

  1. 在虛擬化控制面板中選取設定檔。
  2. 點擊預覽仔細檢視預計建立的虛擬連結。
  3. 確認 Minecraft 遊戲客戶端與啟動器皆已關閉。
  4. 點擊套用設定檔。MineOrganizer 將建立受保護的虛擬連結，絕不會覆蓋使用者原有的常規檔案。
  5. 若有需要，可隨時使用復原上次套用復原變更。

當機報告與記錄檔分析器

當 Minecraft 無法啟動或於遊玩過程中閃退時，使用內建模組分析器可立即找出原因：

  1. 選取遊戲環境並點擊當機與記錄檔分析…。
  2. 選取最新的崩潰報告（crash-reports/crash-*.txt）或遊戲記錄（logs/latest.log）。
  3. 分析器將自動辨識：
    • Minecraft 版本與模組載入器；
    • 錯誤堆疊追蹤 (StackTrace) 中指出造成當機的模組；
    • 問題的核心原因（前置模組缺失、Java 版本不相容或記憶體不足 OutOfMemory）；
    • 具體的排查與解決建議。
  4. 使用複製摘要或複製完整記錄可方便地在社群論壇或 Discord 尋求協助。

Saves

Saves 分頁負責管理目標環境的 Minecraft 世界存檔。直接將存檔 ZIP 壓縮檔或資料夾拖放至此分頁。選取存檔並點擊安裝選取的存檔即可將其複製至作用中環境的 saves 目錄。

Resource packs and shaders

將 ZIP 壓縮檔直接拖放至材質包或光影包表格中。將其指派給設定檔，並透過安全的虛擬連結套用生效。

Configs and Backups

  • 點擊建立備份可將選定環境的 config 資料夾封裝儲存並附加時間戳記。
  • 選取既有備份並點擊還原備份…即可安心復原設定。還原前系統會自動備份當前設定。

Performance & Caching

MineOrganizer 內建本機硬碟持久化雜湊與中繼資料快取。初次解析後，即使管理擁有數千模組的龐大收藏，後續啟動與模組庫掃描也僅需數毫秒，無需再次重新讀取 JAR 檔案。

Troubleshooting

  • 找不到環境：點擊「重新整理」或使用「新增遊戲資料夾…」手動指定路徑。
  • 套用失敗：請先關閉 Minecraft 與啟動器，檢視預覽資訊並檢查檔案寫入權限。
  • 遊戲閃退當機：開啟「當機與記錄檔分析…」檢視造成問題的模組與修復建議。
