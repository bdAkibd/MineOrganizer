MineOrganizer 用户手册

MineOrganizer 是一款集中管理 Minecraft 游戏环境、模组 (Mod)、世界存档、资源包、光影、配置文件及备份的桌面管理工具。它将不同启动器的文件整合到统一的工作区中，帮助您安全地管理和切换完整的游戏内容方案。

核心功能

当您拥有多个 Minecraft 安装实例或模组收藏，并希望实现以下操作时，请使用 MineOrganizer：

  • 自动识别来自 Prism Launcher、CurseForge、Minecraft 官方启动器、TLauncher 以及自定义游戏目录的环境；
  • 维护集中式的高性能模组库，支持拖放导入 (Drag & Drop) 与模组图标缓存；
  • 通过内置的 Modrinth 模组库 直接搜索、下载与一键检查更新模组；
  • 自动检测配置方案中缺失的必要前置模组依赖；
  • 利用集成的崩溃报告与日志分析器快速排查游戏崩溃与闪退问题；
  • 以 .morgpack / .zip 格式完整导出与导入整合包（包括模组、配置文件、资源包、光影与世界存档）；
  • 通过 saves 标签页整理并安装世界存档，无需手动翻找游戏文件夹；
  • 使用安全的虚拟链接应用包含模组、资源包与光影的配置方案；
  • 创建带有时间戳的配置备份，并支持一键安全还原。

安全提示： 预览与环境检查均为只读操作。在应用方案、安装资源、恢复备份或更改活跃环境的文件之前，请务必先退出 Minecraft 游戏客户端。

首次启动

  1. 打开设置 → 语言并选择您的首选界面语言。简体中文与英语以及其他9种语言均获得全面支持。
  2. 在视图菜单中选择浅色或深色主题，设置将自动保存。
  3. 进入游戏环境标签页并点击刷新，MineOrganizer 将扫描已知的启动器位置。
  4. 如果未能自动检测到实例，可使用添加游戏文件夹…、选择 Prism 文件夹…或为官方启动器创建实例。

模组库与拖放导入 (Drag & Drop)

  1. 快速导入 (Drag & Drop)：直接将一个或多个模组 JAR 文件从文件管理器拖放到模组库表格中。系统将立即复制、解析并展示缓存的模组图标。
  2. 标准导入：点击工具栏上的导入 JAR…按钮并选取文件。
  3. 使用即时搜索框和多重过滤器（Minecraft 版本、加载器、兼容性）在大型模组库中迅速定位。
  4. 右键点击任意项目可查看详细元数据、编辑标签、手动重写 Minecraft 版本或移除模组。

Modrinth 模组库与自动更新

从 Modrinth 浏览并安装

  1. 在模组库中点击 Modrinth 模组库。
  2. 输入关键词搜索，并根据 Minecraft 版本和模组加载器（Fabric、Forge、NeoForge、Quilt）进行筛选。
  3. 查看模组描述、作者、下载量与兼容性。点击下载按钮即可将兼容版本的 JAR 文件直接保存到模组库中。

检查更新

  1. 在模组库或方案右键菜单中点击检查更新。
  2. MineOrganizer 将文件的哈希值（SHA-1 / SHA-512）与 Modrinth API 进行比对。
  3. 在更新窗口中勾选目标模组，点击更新所选即可自动下载最新版本。

配置方案与依赖解析

配置方案是针对特定 Minecraft 游戏环境配置的一套专属模组与资源组合。

  1. 进入配置方案标签页，选择目标环境并点击创建方案…。
  2. 选中该方案并点击修改模组…。
  3. 勾选需要包含在该方案中的模组。
  4. 自动依赖解析：如果选取的模组缺少必要的前置库（如 Fabric API），软件将在兼容性一栏提示，并支持一键跳转到 Modrinth 模组库下载。

整合包导出与导入

导出整合包

  1. 选中方案，点击文件菜单或工具栏中的导出整合包…。
  2. 在选项对话框中自由勾选要打包的组件：
    • 模组 (JAR 文件)：方案内选中的模组。
    • 配置 (config 文件夹)：当前环境的模组配置文件。
    • 资源包：resourcepacks 目录下的材质包。
    • 光影包：shaderpacks 目录下的光影包。
    • 世界存档：saves 目录下的存档。
  3. 保存为 .morgpack 或 .zip 格式。

导入整合包

  1. 点击文件菜单中的导入整合包…。
  2. 选择 .morgpack、.zip 或 .mrpack 文件。
  3. 指定新方案名称与目标环境。所有模组、配置、资源和存档将自动解压并就绪！

应用配置方案

  1. 在虚拟化控制区中选择方案。
  2. 点击预览仔细查看计划创建的链接操作。
  3. 确保 Minecraft 游戏客户端及启动器均已关闭。
  4. 点击应用方案。MineOrganizer 将创建受控的虚拟化链接，绝不会覆盖用户原有的常规文件。
  5. 如需撤销，可随时使用撤销上次应用。

崩溃报告与日志分析器

当 Minecraft 无法启动或在游戏过程中发生闪退时，使用内置分析器可即刻查明原因：

  1. 选择游戏环境并点击崩溃与日志分析…。
  2. 选择最新的崩溃报告（crash-reports/crash-*.txt）或运行日志（logs/latest.log）。
  3. 分析器将自动识别：
    • Minecraft 版本与模组加载器；
    • 错误堆栈追踪 (StackTrace) 中指出的引发崩溃的模组；
    • 问题的根本原因（依赖缺失、Java 版本不兼容或 OutOfMemory 内存溢出）；
    • 具体的排查与解决建议。
  4. 使用复制摘要或复制完整日志可方便地在社区论坛或 Discord 寻求技术支持。

Saves

Saves 标签页用于管理目标环境的 Minecraft 世界存档。直接将存档 ZIP 压缩包或文件夹拖放到此页。选择存档并点击安装选中的存档即可将其部署到当前活跃环境的 saves 目录中。

Resource packs and shaders

将 ZIP 压缩包直接拖放到资源包或光影包表格中。将其分配给方案，并通过受保护的安全链接生效。

Configs and Backups

  • 点击创建备份可将选定环境的 config 目录打包保存并附带时间戳。
  • 选择历史备份并点击还原备份…即可安全回退设置。还原前系统会自动备份当前配置。

Performance & Caching

MineOrganizer 配备了本地磁盘持久化哈希与元数据缓存。初次解析后，即使管理拥有数千模组的庞大库，后续启动和库扫描也仅需数毫秒，无需再次读取 JAR 文件。

Troubleshooting

  • 未找到环境：点击「刷新」或使用「添加游戏文件夹…」手动选择游戏路径。
  • 应用方案失败：请先关闭 Minecraft 与启动器，检查预览信息与磁盘写入权限。
  • 游戏闪退崩溃：打开「崩溃与日志分析…」查看故障模组及详细修复指引。
