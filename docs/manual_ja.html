MineOrganizer ユーザーマニュアル

MineOrganizer は、Minecraft のゲーム環境、MOD、ワールドセーブ、リソースパック、シェーダー、プロファイル、設定ファイル、バックアップを一元管理できるデスクトップアプリケーションです。異なるランチャーのファイルを1つの作業スペースにまとめ、コンテンツを安全に切り替えて管理できます。

主な機能

複数の Minecraft インストールや MOD コレクションをお持ちで、以下を行いたい場合に最適です：

  • Prism Launcher、CurseForge、公式ランチャー、TLauncher、カスタムフォルダを自動検出；
  • ドラッグ＆ドロップ（Drag & Drop）とアイコンキャッシュを備えた高速な MOD ライブラリを管理；
  • 内蔵 Modrinth カタログ により MOD を直接検索、ダウンロード、アップデート；
  • プロファイル内の不足している前提 MOD（依存関係）を自動検出；
  • 内蔵 クラッシュレポート＆ログアナライザー で起動障害やゲームクラッシュを瞬時に診断；
  • MOD・設定（config）・リソースパック・シェーダー・ワールドセーブ（saves）を含む完全な MOD パックを .morgpack / .zip 形式でエクスポートおよびインポート；
  • フォルダを手動で開くことなく、saves タブでワールドデータを整理・インストール；
  • 安全な仮想リンクを用いて MOD、テクスチャ、シェーダーを含むプロファイルを適用；
  • 設定ファイルのタイムスタンプ付きバックアップを作成し、ワンクリックで安全に復元。

安全性について: プレビューと環境チェックは読み取り専用です。プロファイルの適用、リソースの導入、バックアップ復元を行う前に、必ず Minecraft を終了してください。

最初の起動

  1. 設定 → 言語 を開き、お好みの表示言語を選択します。日本語と英語をはじめとする全11言語に対応しています。
  2. 表示 メニューからライトまたはダークテーマを選択します。設定は自動で保存されます。
  3. ゲーム環境 タブを開き、更新 を押してランチャーの既知の場所をスキャンします。
  4. 環境が自動検出されない場合は、ゲームフォルダを追加…、Prism フォルダを選択… または公式ランチャー用インスタンスを作成してください。

MOD ライブラリとドラッグ＆ドロップ

  1. 高速インポート（Drag & Drop）: エクスプローラーから MOD の JAR ファイルをライブラリの表へ直接ドラッグ＆ドロップします。瞬時にコピー、解析され、キャッシュされたアイコンが表示されます。
  2. 標準インポート: ツールバーの JAR をインポート… を押してファイルを選択します。
  3. リアルタイム検索とフィルター（Minecraft バージョン、ローダー、互換性）を活用してコレクションを快適に閲覧できます。
  4. 任意の項目を右クリックして、詳細情報の確認、タグの編集、Minecraft バージョンの上書き、フォルダを開く、MOD の削除が可能です。

Modrinth カタログと自動アップデート

Modrinth からの検索と導入

  1. MOD ライブラリ で Modrinth カタログ をクリックします。
  2. キーワードを入力し、Minecraft バージョンとローダー（Fabric、Forge、NeoForge、Quilt）で絞り込みます。
  3. 説明、作者、ダウンロード数、互換性を確認し、ダウンロードボタンを押してライブラリへ直接取り込みます。

更新チェック

  1. ライブラリまたはプロファイルのコンテキストメニューで 更新を確認 をクリックします。
  2. MineOrganizer がファイルのハッシュ値（SHA-1 / SHA-512）を Modrinth API と照合します。
  3. アップデート ウィンドウで対象 MOD を選択し、選択項目を更新 をクリックして最新リリースを自動ダウンロードします。

プロファイルと依存関係の解決

プロファイルとは、特定の Minecraft インストール用に構成された MOD とリソースの組み合わせです。

  1. プロファイル タブを開き、対象環境を選択して プロファイル作成… を押します。
  2. プロファイルを選択し、MOD を編集… をクリックします。
  3. プロファイルに含める MOD にチェックを入れます。
  4. 依存関係の自動解決: 選択した MOD に前提ライブラリ（Fabric API など）が必要な場合、互換性列に警告が表示され、Modrinth から素早く入手できます。

MOD パックのエクスポートとインポート

MOD パックのエクスポート

  1. プロファイルを選択し、ファイル メニューまたはツールバーから MOD パックをエクスポート… を選択します。
  2. ダイアログでパッケージに含めるコンポーネントを選択します：
    • MOD（JAR ファイル）: プロファイルで選択された MOD。
    • 設定（config フォルダ）: 環境内の MOD 設定ファイル。
    • リソースパック: resourcepacks フォルダ内のテクスチャ。
    • シェーダーパック: shaderpacks フォルダ内のシェーダー。
    • ワールドセーブ: saves フォルダ内のセーブデータ。
  3. .morgpack または .zip 形式で保存します。

MOD パックのインポート

  1. ファイル メニューから MOD パックをインポート… を選択します。
  2. .morgpack、.zip、または .mrpack ファイルを選択します。
  3. プロファイル名と対象環境を指定します。すべての MOD、設定、リソース、ワールドが自動展開され、プレイ準備が完了します！

プロファイルの適用

  1. 仮想化パネルでプロファイルを選択します。
  2. プレビュー を押して、計画されているリンク構造を確認します。
  3. Minecraft とランチャーが終了していることを確認します。
  4. プロファイルを適用 を押します。ゲームディレクトリ内に安全な仮想リンクが作成され、ユーザー独自の通常ファイルは決して上書きされません。
  5. 必要に応じて 最後の適用を取り消す を使用して元に戻せます。

クラッシュレポート＆ログアナライザー

Minecraft が起動しない場合やプレイ中に異常終了した場合は、内蔵アナライザーで原因を即座に特定できます：

  1. ゲーム環境を選択し、クラッシュ＆ログ分析… をクリックします。
  2. 最新のクラッシュレポート（crash-reports/crash-*.txt）またはログ（logs/latest.log）を選択します。
  3. アナライザーが以下を自動識別します：
    • Minecraft バージョンと MOD ローダー；
    • エラースタックトレースから特定された原因 MOD；
    • 根本的な問題の診断（依存関係の不足、Java バージョン不一致、メモリ不足 OutOfMemory）；
    • 具体的な推奨対処法。
  4. 概要をコピー または ログ全体をコピー を使用して、サポート窓口や Discord で簡単に共有できます。

Saves

Saves タブは選択された環境の Minecraft ワールドを管理します。ZIP アーカイブまたはフォルダをタブへ直接ドラッグ＆ドロップしてください。ワールドを選択し、選択したセーブデータを導入 をクリックしてアクティブな saves フォルダへコピーします。

Resource packs and shaders

リソースパックやシェーダーの表へ ZIP アーカイブを直接ドラッグ＆ドロップできます。プロファイルへ紐付け、保護されたリンクで適用します。

Configs and Backups

  • バックアップ作成 をクリックして、config フォルダの日時付きアーカイブを作成します。
  • 既存のバックアップを選択し、アーカイブを復元… をクリックして安全に設定を復元できます。

Performance & Caching

MineOrganizer はハッシュ値とメタデータの永続的なディスクキャッシュを搭載しています。初回読み込み以降は、数千個の MOD コレクションであっても JAR ファイルを再読み込みすることなくミリ秒単位で高速起動します。

Troubleshooting

  • 環境が表示されない: 「更新」を押すか、「ゲームフォルダを追加…」で手動指定してください。
  • 適用に失敗する: Minecraft とランチャーを終了し、プレビューとアクセス権限を確認してください。
  • ゲームがクラッシュする: クラッシュ＆ログ分析を開いて原因となった MOD と修正アドバイスを確認してください。
