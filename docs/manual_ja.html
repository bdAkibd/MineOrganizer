MineOrganizer ユーザーマニュアル

MineOrganizer は、Minecraft のゲーム環境、MOD、ワールドセーブ、リソースパック、シェーダー、プロファイル、設定ファイル、バックアップを一元管理できるデスクトップアプリケーションです。

主な機能

Prism Launcher、CurseForge、公式ランチャー、カスタムフォルダの自動検出；ドラッグ＆ドロップ（Drag & Drop）とアイコンキャッシュを備えた高速 MOD ライブラリ；内蔵 Modrinth カタログ による MOD の検索・ダウンロード・一括アップデート；不足している依存関係の自動検出；ゲームクラッシュを瞬時に特定する クラッシュレポート＆ログアナライザー；MOD・設定（config）・リソースパック・シェーダー・ワールドセーブ（saves）を含む完全な MOD パックのエクスポート／インポート；安全なプロファイル適用とバックアップ管理。

安全性について: プロファイルの適用やバックアップ復元を行う前に、必ず Minecraft を終了してください。

MOD ライブラリとドラッグ＆ドロップ

JAR ファイルをライブラリの表へ直接ドラッグ＆ドロップするだけで即座にインポートされます。MOD のメタデータと内蔵アイコンが抽出・キャッシュされ、素早い検索やバージョン／ローダーによる絞り込みが可能です。

Modrinth カタログと自動アップデート

  • Modrinth カタログ: ブラウザを開かずに対応 MOD を検索・ダウンロードできます。
  • 更新チェック: ファイルのハッシュ値を Modrinth API と照合し、最新バージョンへワンクリックで更新できます。

プロファイルと依存関係の解決

環境ごとに最適な MOD の組み合わせをプロファイルとして管理できます。必要な前提 MOD（Fabric API など）が不足している場合は自動で警告が表示され、Modrinth から素早く入手できます。

MOD パックのエクスポートとインポート

プロファイルを .morgpack または .zip 形式でエクスポートできます。MOD 本体だけでなく、config フォルダ、リソースパック、シェーダー、ワールドデータ（saves）をまとめてパッケージ化し、別の環境へ簡単にインポートして即プレイできます。

クラッシュログアナライザー

ゲームが起動しない場合やクラッシュした際、crash-reports や latest.log を自動解析し、原因となった MOD や Java の互換性問題、メモリ不足（OutOfMemory）を特定して解決策を提案します。

セーブデータ、リソースパック、シェーダー

ワールドデータやグラフィックパックもドラッグ＆ドロップに対応。ディスクキャッシュによる超高速起動で、数千個の MOD でも快適に動作します。
