MineOrganizer User Manual

MineOrganizer is a desktop manager for Minecraft game environments, mods, saves, resource packs, shaders, profiles, configuration files, and backups. It brings files from different launchers into one workspace and helps you manage and switch complete sets of game content safely.

What the program is for

Use MineOrganizer when you have several Minecraft installations or mod collections and want to:

  • Detect environments from Prism Launcher, CurseForge, the official Minecraft launcher, TLauncher, and custom game directories;
  • Keep a centralized, high-performance mod library with Drag & Drop import and cached mod icons;
  • Search, download, and update mods directly through the built-in Modrinth Catalog;
  • Automatically detect missing mod dependencies in profiles;
  • Quickly diagnose game crashes using the integrated Crash Report & Log Analyzer;
  • Export and import complete modpacks (including mods, configs, resource packs, shaders, and saves) via .morgpack / .zip;
  • Store, organize, and install worlds through the saves tab without digging into game directories manually;
  • Apply profiles containing mods, resource packs, and shaders using virtualized links;
  • Create timestamped backups of configuration files and restore them in one click.

Safety: Preview and environment checks are read-only. Close Minecraft before applying a profile, installing assets, restoring backups, or modifying files in an active environment.

First launch

  1. Open Settings → Language and choose your preferred interface language. English and Russian are fully supported, along with 9 other languages.
  2. Choose a light or dark theme from View. Settings are saved automatically.
  3. Open Game environments and press Refresh. MineOrganizer scans known launcher locations.
  4. If an installation was not detected, use Add game folder…, Choose Prism folder…, or create an instance for the official launcher.

Mod library & Drag and Drop

  1. Drag & Drop import: drag one or more mod JAR files from your file manager directly onto the mod library table. They are immediately copied to the library, parsed, and assigned cached icons.
  2. Standard import: press Import JAR… on the toolbar and select files.
  3. Use live search and filters (Minecraft version, loader, compatibility) to navigate large collections.
  4. Right-click any item to view detailed info, edit tags, override Minecraft versions, open file locations, or remove items.

Modrinth Catalog & Auto-Updates

Browsing and installing from Modrinth

  1. In the Mod library, click Modrinth catalog.
  2. Search by keyword and filter by Minecraft version and mod loader (Fabric, Forge, NeoForge, Quilt).
  3. View mod descriptions, authors, downloads, and compatibility. Click the download icon to download the compatible JAR directly into your library.

Checking for updates

  1. Click Check updates in the library or from a profile's context menu.
  2. MineOrganizer verifies file hashes (SHA-1 / SHA-512) against Modrinth's API.
  3. In the Updates window, review available updates, select desired mods, and click Update selected to download the latest releases automatically.

Profiles & Dependency Resolution

A profile is a named set of mods and assets configured for a specific Minecraft installation.

  1. Open Profiles, select a target environment, and click Create profile….
  2. Select the profile and click Edit mods….
  3. Mark the mods to include in the profile.
  4. Automatic dependency resolution: if a chosen mod requires another library or mod (such as Fabric API), MineOrganizer flags the missing dependency in the compatibility column and offers to open the Modrinth catalog to fetch it immediately.

Modpack Export & Import

Exporting a modpack

  1. Select a profile and choose Export modpack… from the File menu or toolbar.
  2. In the export dialog, choose which components to package:
    • Mods (JAR files): selected profile mods.
    • Configurations (config folder): mod configurations from the environment.
    • Resource packs: texture packs from resourcepacks.
    • Shader packs: shaders from shaderpacks.
    • Saves: world saves from saves.
  3. Save the archive as .morgpack or .zip.

Importing a modpack

  1. Choose Import modpack… from the File menu.
  2. Select the .morgpack, .zip, or .mrpack file.
  3. Specify a profile name and target environment. All mods, configs, assets, and saves will be extracted and prepared automatically!

Applying a profile

  1. Select the profile in the virtualization panel.
  2. Press Preview and review every proposed filesystem link.
  3. Ensure Minecraft and its launcher are closed.
  4. Press Apply profile. MineOrganizer creates managed symbolic/hard links from the library into the game directory. Regular files are never overwritten.
  5. Use Rollback last application to revert changes whenever needed.

Crash Report & Log Analyzer

When Minecraft fails to start or crashes during gameplay, use the built-in log analyzer to identify the cause instantly:

  1. Select the game environment and click Analyze crash & logs….
  2. Select the latest crash report (crash-reports/crash-*.txt) or game log (logs/latest.log).
  3. The analyzer automatically identifies:
    • Minecraft version and mod loader;
    • Suspect mods extracted from the crash stack trace;
    • Diagnosis of the root issue (missing dependencies, Java version incompatibilities, or OutOfMemory errors);
    • Actionable suggested solutions.
  4. Use Copy summary or Copy full log to easily share diagnostics on forums or Discord.

Saves

The Saves tab manages Minecraft worlds for the selected environment. Drag and drop world ZIP archives or folders directly onto the Saves tab. Select a save and click Install selected save to copy it into the active environment's saves folder.

Resource packs and shaders

Drag and drop ZIP archives directly onto the Resource packs or Shaders tables. Select archives, assign them to a profile, and apply them using safe link virtualization.

Configs and Backups

  • Click Create backup to make a timestamped ZIP archive of the selected environment's config folder.
  • Select a backup and click Restore archive… to restore settings safely. Current configs are automatically backed up before any restoration.

Performance & Caching

MineOrganizer includes a disk-persistent hash and metadata cache. File hashes and mod properties are cached after initial inspection, allowing subsequent launches and library scans with thousands of mods to complete in milliseconds without re-reading JAR archives from disk.

Troubleshooting

  • Environment missing: click Refresh or use Add game folder… to select the directory manually.
  • Applying fails: close Minecraft and the launcher, inspect Preview, and verify file permissions.
  • Game crashes: open Analyze crash & logs… to see the offending mod and suggested fix.
